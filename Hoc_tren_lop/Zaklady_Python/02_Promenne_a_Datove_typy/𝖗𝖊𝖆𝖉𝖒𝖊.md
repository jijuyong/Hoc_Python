# **02 - Biến và Kiểu dữ liệu**

Trong bài học này, bạn sẽ học cách lưu trữ thông tin trong chương trình, cách làm việc với dữ liệu và cách nhận dữ liệu từ người dùng.

## **1. Biến (Variables)**

Biến là một vùng nhớ có tên trong bộ nhớ máy tính, dùng để lưu trữ một giá trị.

* **Phép gán:** Để gán giá trị cho biến, chúng ta sử dụng dấu bằng `=`.
* **Kiểu dữ liệu động (Dynamic Typing):** Trong Python, bạn **không cần khai báo kiểu dữ liệu** (ví dụ: `int x`). Python sẽ tự động xác định kiểu dữ liệu dựa trên giá trị mà bạn gán cho biến.

### **Quy tắc đặt tên biến (Naming Conventions)**

Trong Python, chúng ta tuân theo quy tắc **snake_case**:

* Đúng: `so_mang`, `ten_nguoi_dung`, `toc_do_toi_da`
* Sai: `SoMang` (CamelCase thường dùng để đặt tên lớp), `tocDoToiDa`
* Tên biến **không được bắt đầu bằng số** và **không được chứa khoảng trắng**.

## **2. Các kiểu dữ liệu cơ bản**

Python có rất nhiều kiểu dữ liệu được tích hợp sẵn. Dưới đây là các kiểu dữ liệu cơ bản (scalar).

### **Kiểu số**

| Kiểu | Tên trong Python | Mô tả | Ví dụ |
| :---- | :---- | :---- | :---- |
| **Integer** | `int` | Số nguyên (dương hoặc âm, không giới hạn kích thước) | `5`, `-10`, `42`, `1000000` |
| **Float** | `float` | Số thực (luôn sử dụng dấu chấm thập phân, theo chuẩn IEEE 754) | `3.14`, `-0.01`, `2.0`, `1.5e2` |
| **Complex** | `complex` | Số phức (gồm phần thực và phần ảo) | `2+3j`, `5j` |

### **Kiểu văn bản và dữ liệu byte**

| Kiểu | Tên trong Python | Mô tả | Ví dụ |
| :---- | :---- | :---- | :---- |
| **String** | `str` | Chuỗi ký tự (văn bản Unicode) | `"Xin chào"`, `'Python'` |
| **Bytes** | `bytes` | Dãy byte không thể thay đổi (giá trị từ 0–255) | `b"Data"`, `b'\x00\xFF'` |
| **Bytearray** | `bytearray` | Dãy byte có thể thay đổi | `bytearray(5)` |

### **Các kiểu dữ liệu khác**

| Kiểu | Tên trong Python | Mô tả | Ví dụ |
| :---- | :---- | :---- | :---- |
| **Boolean** | `bool` | Giá trị đúng hoặc sai | `True`, `False` |
| **NoneType** | `NoneType` | Đại diện cho giá trị rỗng hoặc không có giá trị | `None` |

> **Mẹo:** Bạn có thể kiểm tra kiểu dữ liệu của một biến bằng hàm `type(bien)`.

## **3. Ép kiểu dữ liệu (Type Casting)**

Trong nhiều trường hợp, chúng ta cần chuyển đổi kiểu dữ liệu. Ví dụ, số `5` và chuỗi `"5"` có cách hoạt động hoàn toàn khác nhau.

* `int("123")` → Chuyển chuỗi thành số nguyên.
* `float("3.14")` → Chuyển chuỗi thành số thực.
* `str(100)` → Chuyển số thành chuỗi (rất hữu ích khi hiển thị kết quả).
* `bool(0)` → Chuyển thành `False` (mọi giá trị khác `0` hoặc chuỗi rỗng sẽ là `True`).

```python
a = "10"
b = "20"

print(a + b)              # Kết quả: "1020" (nối chuỗi)
print(int(a) + int(b))    # Kết quả: 30 (cộng hai số)
```

## **4. Nhập dữ liệu từ người dùng (`input`)**

Để tương tác với người dùng, Python cung cấp hàm `input()`.

* Chương trình sẽ tạm dừng và chờ người dùng nhập dữ liệu rồi nhấn **Enter**.
* **Quan trọng:** Hàm `input()` **LUÔN trả về chuỗi (`str`)**, ngay cả khi người dùng nhập một con số.

Nếu muốn thực hiện các phép tính với giá trị vừa nhập, bạn cần chuyển đổi kiểu dữ liệu ngay lập tức.

```python
tuoi = int(input("Bạn bao nhiêu tuổi? "))
```

## **5. Các Kiểu dữ liệu khác**
| Kiểu       | Tên trong Python | Mô tả | Ví dụ                                                                                      |
|:-----------|:-----------------| :---- |:-------------------------------------------------------------------------------------------|
| **Lists**  | `list()/[]`      | Danh sách, có thứ tự, thay đổi được | list1 = [1,2,3,"apple"] / list1 = list((1,2,3))                                            |
| **Tuples** | `()/,/tuple()`   | Bộ giá trị, không thay đổi được | `t1 =(1, "apple", 3.14)/ t1= 1, "apple", 3.14/ tuple_1_phan_tu= (5,)/ t1 = tuple([1,2,3])` |


Để tương tác với người dùng, Python cung cấp hàm `input()`.

* Chương trình sẽ tạm dừng và chờ người dùng nhập dữ liệu rồi nhấn **Enter**.
* **Quan trọng:** Hàm `input()` **LUÔN trả về chuỗi (`str`)**, ngay cả khi người dùng nhập một con số.

Nếu muốn thực hiện các phép tính với giá trị vừa nhập, bạn cần chuyển đổi kiểu dữ liệu ngay lập tức.

```python
tuoi = int(input("Bạn bao nhiêu tuổi? "))
```

### **2. Máy tính BMI**

Nhập từ người dùng:

- Cân nặng (kg) dưới dạng `float`.
- Chiều cao (m) dưới dạng `float`.

Tính chỉ số BMI theo công thức:

```text
BMI = can_nang / (chieu_cao * chieu_cao)
```

Sau đó in kết quả ra màn hình.
