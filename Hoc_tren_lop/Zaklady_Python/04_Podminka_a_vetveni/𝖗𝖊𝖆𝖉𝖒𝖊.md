# **04 - Điều kiện và Rẽ nhánh (Podmínky a Větvení)**

Cho đến nay, các chương trình của chúng ta chạy theo tuyến tính – dòng này qua dòng khác, từ trên xuống dưới. Việc rẽ nhánh cho phép chúng ta thay đổi dòng chảy này: chỉ thực thi một phần mã nhất định khi một điều kiện nào đó được thỏa mãn.

## **1. Cấu trúc `if`**

Thành phần cơ bản nhất của việc đưa ra quyết định. Nếu biểu thức sau từ khóa `if` là đúng (`True`), khối mã được thụt lề sẽ được thực thi.

```python
cislo = 10

if cislo > 5:  
    print("Cislo je vetsi nez 5")  
    # Dòng này thuộc về khối điều kiện  
      
print("Tohle se vypise vzdy")
```

## **2. Cấu trúc `else`**

Phần tùy chọn, sẽ được thực thi nếu điều kiện trong `if` **không** được thỏa mãn (sai).

```python
vek = 15

if vek >= 18:  
    print("Vstup povolen.")  
else:  
    print("Vstup zakazan.")
```

## **3. Cấu trúc `elif`**

Nếu chúng ta có nhiều hơn hai khả năng, chúng ta sử dụng `elif` (viết tắt của "else if"). Python sẽ kiểm tra các điều kiện theo thứ tự. Ngay khi gặp điều kiện đúng đầu tiên, nó sẽ thực thi khối mã đó và bỏ qua phần còn lại.

```python
body = 85

if body >= 90:  
    znamka = "A"  
elif body >= 75:  
    znamka = "B"  
elif body >= 50:  
    znamka = "C"  
else:  
    znamka = "F"
```

## **4. Điều kiện lồng nhau (Nested Ifs)**

Chúng ta có thể đặt các câu lệnh điều kiện bên trong nhau. Tuy nhiên, không nên lạm dụng để giữ cho mã nguồn dễ đọc.

```python
if uzivatel_prihlasen:  
    if ma_admin_prava:  
        print("Vitej v administraci")  
    else:  
        print("Vitej uzivateli")  
else:  
    print("Prosim, prihlaste se")
```

## **5. Toán tử ba ngôi (If trên một dòng)**

Đối với gán giá trị đơn giản dựa trên điều kiện, có một cú pháp viết tắt.

**Cú pháp:** `gia_tri_neu_dung if dieu_kien else gia_tri_neu_sai`

```python
stav = "dospely" if vek >= 18 else "nezletily"
```

## **6. Cấu trúc `match-case` (Python 3.10+)**

Giải pháp thay thế hiện đại cho chuỗi `if-elif-else` dài khi chúng ta so sánh một biến với nhiều giá trị cụ thể (tương tự như `switch` trong C++ hoặc Java).

```python
status_kod = 404

match status_kod:  
    case 200:  
        print("OK")  
    case 404:  
        print("Nenalezeno")  
    case 500:  
        print("Chyba serveru")  
    case _:  
        print("Neznamy stav") # _ hoạt động như mặc định (else)  
```
