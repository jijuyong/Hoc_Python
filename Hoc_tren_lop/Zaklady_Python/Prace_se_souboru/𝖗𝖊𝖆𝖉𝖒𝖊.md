# **Làm việc với tệp trong Python**

Khả năng đọc dữ liệu từ tệp và ghi dữ liệu vào tệp là điều cần thiết để lưu trữ kết quả của chương trình, tải cấu hình hoặc xử lý các tập dữ liệu lớn. Python sử dụng hàm tích hợp `open()` cho việc này.

## **Cú pháp cơ bản**

```python
file = open("soubor.txt", mode="r", encoding="utf-8")
# ... làm việc với tệp ...
file.close() # QUAN TRỌNG: Tệp phải được đóng!
```

### **Các chế độ mở tệp (Modes)**

Đối số này xác định chúng ta sẽ làm gì với tệp:

| Chế độ | Mô tả | Nếu tệp không tồn tại | Nếu tệp đã tồn tại |
| :---- | :---- | :---- | :---- |
| `'r'` | **Read** (đọc) - mặc định | Sẽ phát sinh lỗi `FileNotFoundError` | Đọc từ đầu |
| `'w'` | **Write** (ghi) | Tạo tệp mới | **Xóa nội dung và ghi đè!** |
| `'a'` | **Append** (thêm) | Tạo tệp mới | Ghi vào cuối tệp |
| `'x'` | **Exclusive creation** (tạo độc quyền) | Tạo tệp mới | Sẽ phát sinh lỗi `FileExistsError` |

## **Trình quản lý ngữ cảnh (`with`) - Best Practice**

Trong thực tế, chúng ta hiếm khi sử dụng `file.close()`. Thay vào đó, chúng ta sử dụng khối `with`. Nó đảm bảo rằng tệp **luôn được đóng một cách an toàn**, ngay cả khi xảy ra lỗi trong chương trình.

```python
# Cách đúng và an toàn:
with open("data.txt", "w", encoding="utf-8") as f:
    f.write("Xin chào thế giới")
# Đến đây tệp đã được đóng
```

**Quan trọng:** Luôn chỉ định `encoding="utf-8"` khi làm việc với tiếng Việt hoặc các ký tự Unicode, nếu không các ký tự có thể hiển thị không chính xác.

## **Đọc từ tệp**

Có một số cách để lấy dữ liệu từ tệp:

1. **`read()`** – Đọc toàn bộ tệp thành một chuỗi lớn.
   ```python
   content = f.read()
   ```

2. **`readline()`** – Mỗi lần đọc chỉ một dòng (và di chuyển con trỏ đến dòng tiếp theo).
3. **`readlines()`** – Đọc tất cả các dòng và trả về chúng dưới dạng **danh sách** các chuỗi.
4. **Lặp qua tệp bằng vòng lặp** – Hiệu quả nhất đối với các tệp lớn.
   ```python
   for radek in f:
       print(radek.strip()) # .strip() loại bỏ các ký tự xuống dòng vô hình ở cuối dòng
   ```

## **Ghi vào tệp**

* **`write(string)`** – Ghi một chuỗi. Lưu ý: phương thức này không tự động thêm dòng mới `\n`, bạn phải tự thêm vào.
* **`writelines(list)`** – Ghi một danh sách các chuỗi.

## **Chế độ nhị phân**
- mặc định open la chế độ text - đọc/nghi chuỗi str, tự mã hóa sang byte
- thêm `b` ("rb", "wb","ab") => nhị phân - đọc/nghi thẳng bytes, ko encoding
- dùng cho file ko phải chữ: ảnh,video,PDF, file nén....mở loại này bằng text mode sẽ bị hỏng data

```python
# ghi chuoi -> bytes roi ghi (mo "wb")
data = "xin chao".encode("utf-8")
with open("data.bin","wb") as f:
    f.write(data)

#doc: doc ra bytes roi decode (mo "rb")
with open("data.bin","rb") as f:
   b = f.read()
print(b)
print(b.decode("utf-8"))

```

## **Thêm "+" - vừa đọc vừa ghi**
- thêm + ("r+","w+","a+") -> mở file để vừa đọc vừa ghi
- con trỏ = vị trí hiện tại trong file - nơi lần đọc/ghi kế tiếp xảy ra
- f.tell() cho biết con trỏ đang ở đâu, f.seek(0) nhảy con trỏ về đầu file (seek(n)= tới byte n)


| Chế độ | Mô tả                         | Đọc ngay được gì                    | Ghi vào đâu                      |
|:-------|:------------------------------|:------------------------------------|:---------------------------------|
| `'r+'` | đầu file(vị trí 0)            | nội dung cũ - đọc đc ngay           | đè lên chữ cũ, tp̀ vị trí con trỏ |
| `'w+'` | Đầu(0) - file vừa bị xóa sạch | rỗng(file đang trống)               | ở đầu, đọc lại phải seek(0)      |
| `'a+'` | cuối file                     | rỗng! con trỏ ở cuối-> phải seek(0) | Luôn ở cuối (dù đã seek 0)       |

**CÁC THUỘC TÍNH KHÁC**
- `f.name` - tra tên của file khi đang mở  
- `f.mode` - tra mode của file khi đang mở  
- `f.closed` - trả về TRUE khi FILE đã đóng 
- `f.encoding` - xem file đang dùng bộ mã nào
