# **03 - Các toán tử**

Toán tử là các ký hiệu dùng để thực hiện các phép toán với một hoặc nhiều giá trị (**operand**). Trong Python, các toán tử được chia thành một số nhóm.

## **1. Các toán tử số học**

Dùng để thực hiện các phép tính toán học thông thường.

| Toán tử | Tên | Mô tả | Ví dụ | Kết quả |
| :---- | :---- | :---- | :---- | :---- |
| `+` | Phép cộng | Cộng hai số | `10 + 5` | `15` |
| `-` | Phép trừ | Lấy số thứ nhất trừ số thứ hai | `10 - 5` | `5` |
| `*` | Phép nhân | Nhân hai số | `10 * 5` | `50` |
| `/` | Phép chia | Luôn trả về số thập phân (`float`) | `10 / 2` | `5.0` |
| `//` | Phép chia lấy phần nguyên | Chỉ trả về phần nguyên của kết quả | `10 // 3` | `3` |
| `%` | Phép modulo | Trả về phần dư sau phép chia | `10 % 3` | `1` |
| `**` | Phép lũy thừa | Nâng một số lên số mũ cho trước | `2 ** 3` | `8` |

**Lưu ý về Modulo (`%`):** Toán tử này cực kỳ hữu ích trong lập trình. Ví dụ, nó được sử dụng để kiểm tra xem một số có phải là số chẵn hay không (`x % 2 == 0`), hoặc để lặp lại các chu kỳ (ví dụ: các ngày trong tuần).

## **2. Các toán tử dùng với chuỗi**

Một số toán tử số học cũng có thể được sử dụng với văn bản, nhưng cách hoạt động sẽ khác.

| Toán tử | Mô tả | Ví dụ | Kết quả |
| :---- | :---- | :---- | :---- |
| `+` | Nối chuỗi (concatenation) | `"Ahoj " + "světe"` | `"Ahoj světe"` |
| `*` | Lặp lại chuỗi | `"Na" * 3` | `"NaNaNa"` |

## **3. Các toán tử gán**

Dùng để viết ngắn gọn khi thay đổi giá trị của một biến dựa trên giá trị ban đầu của biến đó.

| Cách viết | Tương đương |
| :---- | :---- |
| `x = 5` | Phép gán thông thường |
| `x += 2` | `x = x + 2` |
| `x -= 2` | `x = x - 2` |
| `x *= 2` | `x = x * 2` |
| `x /= 2` | `x = x / 2` |

## **4. Các toán tử so sánh**

Luôn trả về giá trị `True` hoặc `False`.

| Toán tử | Ý nghĩa | Ví dụ (`x=5`) |
| :---- | :---- | :---- |
| `==` | Bằng (chú ý phải có hai dấu bằng!) | `x == 5` (`True`) |
| `!=` | Khác | `x != 5` (`False`) |
| `>` | Lớn hơn | `x > 2` (`True`) |
| `<` | Nhỏ hơn | `x < 2` (`False`) |
| `>=` | Lớn hơn hoặc bằng | `x >= 5` (`True`) |
| `<=` | Nhỏ hơn hoặc bằng | `x <= 10` (`True`) |

**Điểm đặc biệt của Python:** Trong Python, bạn có thể nối nhiều phép so sánh liên tiếp.

* `0 < x < 10` (Có nghĩa là: x lớn hơn 0 **VÀ ĐỒNG THỜI** nhỏ hơn 10)

## **5. Các toán tử logic**

Dùng để kết hợp nhiều điều kiện.

| Toán tử | Mô tả | Ví dụ |
| :---- | :---- | :---- |
| `and` | Cả hai mệnh đề đều đúng đồng thời | `True and False` -> `False` |
| `or` | Ít nhất một mệnh đề đúng | `True or False` -> `True` |
| `not` | Đảo ngược giá trị (phủ định) | `not True` -> `False` |

### **Bảng chân trị của AND và OR**

| A | B | A and B | A or B |
| :---- | :---- | :---- | :---- |
| False | False | **False** | **False** |
| False | True | **False** | **True** |
| True | False | **False** | **True** |
| True | True | **True** | **True** |

## **6. Các toán tử thành viên (Membership)**

Dùng để kiểm tra xem một giá trị có nằm trong một chuỗi hoặc một cấu trúc dữ liệu dạng tuần tự hay không (ví dụ: chuỗi hoặc danh sách).

* `in` - trả về `True` nếu tìm thấy giá trị.
* `not in` - trả về `True` nếu **KHÔNG** tìm thấy giá trị.

```python
"a" in "auto"  # True
"z" in "auto"  # False
```
