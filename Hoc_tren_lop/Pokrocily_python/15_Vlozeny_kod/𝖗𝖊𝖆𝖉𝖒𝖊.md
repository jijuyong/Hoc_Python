# **15 - Mã nhúng (Mở rộng Python bằng C)**

Python rất phù hợp để phát triển nhanh, nhưng có thể chậm khi thực hiện các phép tính nặng (ví dụ: xử lý ảnh, mật mã học, các phép toán ma trận). Trong những trường hợp như vậy, người ta thường sử dụng các **phần mở rộng (extension)** viết bằng ngôn ngữ C hoặc C++.

Nhiều thư viện nổi tiếng (NumPy, TensorFlow, Pandas) được viết theo cách này. Python chỉ đóng vai trò như một “bộ điều khiển” cho phần lõi tốc độ cao được viết bằng C/C++.

## **Cách thức hoạt động**

1. Viết mã bằng **C/C++**.
2. Thêm các **hàm wrapper** đặc biệt bằng tệp tiêu đề `Python.h`. Những hàm này đóng vai trò cầu nối — chuyển đổi các đối tượng Python (`PyObject`) thành kiểu dữ liệu C (`int`, `char*`) và ngược lại.
3. **Biên dịch** mã thành thư viện dùng chung (`.so` trên Linux, `.pyd` trên Windows).
4. Trong Python, chỉ cần nhập thư viện bằng lệnh `import muj_modul`.

## **Python C API**

Nền tảng của cách làm này là thư viện `Python.h`, cung cấp quyền truy cập vào các cấu trúc nội bộ của trình thông dịch Python.

### **Các hàm quan trọng**

* `PyArg_ParseTuple(args, "i", &x)`: Nhận các đối số từ Python và lưu chúng vào các biến C. Chuỗi định dạng `"i"` biểu thị số nguyên, `"s"` biểu thị chuỗi, v.v.
* `Py_BuildValue("i", vysledek)`: Đóng gói kết quả từ C trở lại thành một đối tượng Python.

## **Biên dịch (`setup.py`)**

Python có công cụ tiêu chuẩn `setuptools` để biên dịch các phần mở rộng.

```python
from setuptools import setup, Extension

modul = Extension('nazev_modulu', sources=['soubor.c'])

setup(ext_modules=[modul])
```

Lệnh biên dịch (tạo tệp ngay trong thư mục hiện tại):

```shell
python3 setup.py build_ext --inplace
```

## **Các lựa chọn thay thế**

Viết trực tiếp bằng C API khá tốn công. Có một số công cụ hiện đại hơn:

* **Cython:** Viết mã gần giống Python, sau đó mã được chuyển đổi thành C.
* **pybind11:** Thư viện C++ hiện đại giúp kết nối C++ với Python rất dễ dàng.
* **ctypes / cffi:** Cho phép gọi các thư viện C có sẵn mà không cần biên dịch wrapper.

## **Bài tập**

### **1. Về đích (mã C)**

Tạo tệp `mymath.c`. Trong tệp này, hãy viết một hàm bằng ngôn ngữ C nhận vào hai số nguyên và trả về tích của chúng.

Thêm phần mã khung (boilerplate) cần thiết bằng `Python.h` để đưa hàm này ra ngoài dưới dạng mô-đun `mymath`.

### **2. Biên dịch và kiểm thử**

Tạo tệp `setup.py` để biên dịch mô-đun `mymath`.

1. Chạy lệnh build (`python setup.py build_ext --inplace`).
2. Tạo tập lệnh `test.py`, trong đó nhập `mymath`, gọi hàm của bạn và in kết quả.
