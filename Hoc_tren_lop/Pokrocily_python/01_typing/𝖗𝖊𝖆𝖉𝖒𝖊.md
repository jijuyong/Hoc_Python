# **06 - Type Hinting (Gợi ý kiểu dữ liệu)**

Python là một ngôn ngữ lập trình kiểu động (dynamically typed). Điều này có nghĩa là một biến có thể thay đổi kiểu dữ liệu của nó theo thời gian và trình thông dịch không kiểm tra kiểu dữ liệu trước khi chạy chương trình.

Tuy nhiên, đối với các dự án lớn, điều này có thể dẫn đến các lỗi khó tìm. Do đó, **Type Hinting** đã được thêm vào Python.

## **Nó là gì?**

Type Hinting cho phép lập trình viên "gợi ý" kiểu dữ liệu mà họ mong đợi.
Quan trọng: Python bỏ qua các chú thích này khi chạy! Chương trình vẫn sẽ chạy ngay cả khi các kiểu dữ liệu không khớp. Nó phục vụ chủ yếu cho:

1. **IDE (gợi ý, tự động hoàn thành mã - autocomplete).**
2. **Phân tích tĩnh (các công cụ như `mypy`).**
3. **Tài liệu hóa mã nguồn.**

## **Cú pháp cơ bản**

```python
# Biến
tuoi: int = 25
ten: str = "Petr"
dang_hoat_dong: bool = True

# Hàm (tham số -> giá trị trả về)
def chao_hoi(ten: str) -> str:
    return "Xin chào " + ten
```

## **Các kiểu dữ liệu phức hợp (Collections)**

Từ Python 3.9, chúng ta có thể sử dụng các kiểu dữ liệu có sẵn với dấu ngoặc vuông.

* `list[int]` - Danh sách các số nguyên
* `dict[str, int]` - Từ điển, trong đó khóa là chuỗi và giá trị là số nguyên
* `tuple[int, int]` - Bộ gồm hai số
* `set[str]` - Tập hợp các chuỗi

## **Các kiểu dữ liệu đặc biệt**

### **1. Union (Hợp) - `|`**

Được sử dụng khi một biến có thể thuộc nhiều kiểu dữ liệu khác nhau.

* Cách viết cũ: `Union[int, str]` (yêu cầu `from typing import Union`)
* Cách viết mới (Python 3.10+): `int | str`

### **2. Optional - `| None`**

Được sử dụng khi một giá trị có thể thuộc một kiểu dữ liệu nào đó hoặc là `None`.

* Ví dụ: `nguoi_dung: str | None = None # tra ve str hoac none` 

### **3. Any**

Kiểu `Any` có nghĩa là "ở đây có thể là bất cứ thứ gì". Về cơ bản, bạn đang tắt tính năng kiểm tra kiểu cho biến đó. Hãy sử dụng cẩn thận.

### **4. Các lớp tự định nghĩa (Custom Classes)**

Bạn cũng có thể sử dụng tên của một lớp tự định nghĩa làm kiểu dữ liệu.

```python
def xu_ly_sinh_vien(sinh_vien: SinhVien) -> None:
    ...
```
---
## **Bài tập**

### **1. Hàm có định nghĩa kiểu**
Viết hàm `tinh_chu_vi`, hàm này:
- Nhận một tham số `canh` (kiểu `int` hoặc `float`).
- Trả về `float`.
- Tính chu vi hình vuông (cạnh * 4).

### **2. Bộ sưu tập (Collections)**
Tạo một biến `sinh_vien`, biến này sẽ là một từ điển (dictionary) với khóa là tên (`str`) và giá trị là tuổi (`int`). Sử dụng chú thích kiểu chính xác.

### **3. Optional**
Viết hàm `tim_nguoi_dung(id: int)`, hàm này trả về tên người dùng (`str`) hoặc `None` nếu người dùng không tồn tại (trả về `None` cho bất kỳ ID nào > 10). Đừng quên kiểu trả về là `str | None` (hoặc `Optional[str]`).
