# 06 – Phương thức ma thuật (Dunder methods)

Phương thức ma thuật (*Dunder methods*, viết tắt của *Double Underscore methods*) là những phương thức đặc biệt trong Python có tên bắt đầu và kết thúc bằng hai dấu gạch dưới. Chúng cho phép ta định nghĩa cách đối tượng hoạt động khi sử dụng các phép toán và hàm tiêu chuẩn.

Nhờ đó, các đối tượng do chúng ta tự tạo có thể hoạt động tự nhiên giống các kiểu dữ liệu có sẵn như `int`, `str` và `list`.

## 1. Biểu diễn đối tượng (`__str__` và `__repr__`)

Khi in một đối tượng bằng `print(obj)`, nếu chưa tùy chỉnh, Python có thể hiển thị nội dung như `<__main__.Trida object at 0x00...>`, vốn không dễ đọc.

- **`__str__(self)`** – Được gọi khi dùng `print()` hoặc `str()`. Phương thức này trả về mô tả dễ đọc dành cho người dùng.
- **`__repr__(self)`** – Được gọi bởi `repr()` và thường xuất hiện trong môi trường tương tác. Phương thức này cung cấp biểu diễn chi tiết hơn dành cho lập trình viên; lý tưởng nhất là có thể dùng để tái tạo đối tượng.

```python
class Kniha:
    def __init__(self, nazev):
        self.nazev = nazev

    def __str__(self):
        return f"Sách: {self.nazev}"


k = Kniha("Người Hobbit")
print(k)  # Sách: Người Hobbit
```

## 2. Nạp chồng toán tử (Operator Overloading)

Nếu muốn có thể cộng, trừ, nhân hoặc so sánh các đối tượng, ta cần triển khai những phương thức ma thuật tương ứng.

- **`__add__(self, other)`** – Định nghĩa phép cộng `+`.
- **`__sub__(self, other)`** – Định nghĩa phép trừ `-`.
- **`__mul__(self, other)`** – Định nghĩa phép nhân `*`.
- **`__eq__(self, other)`** – Định nghĩa phép so sánh bằng `==`.
- **`__lt__(self, other)`** – Định nghĩa phép so sánh nhỏ hơn `<`.

### Ví dụ: Cộng hai vector

Khi định nghĩa `__add__`, ta có thể viết `v3 = v1 + v2`. Python sẽ gọi phương thức cộng của `v1` với `v2`.

## 3. Một số phương thức hữu ích khác

- **`__len__(self)`** – Được gọi khi dùng `len(obj)`.
- **`__getitem__(self, index)`** – Cho phép truy cập đối tượng bằng chỉ số, ví dụ `obj[index]`.
- **`__call__(self)`** – Cho phép gọi một đối tượng như gọi hàm, ví dụ `obj()`.

Sử dụng phương thức ma thuật giúp mã Python trở nên **Pythonic** — rõ ràng, dễ đọc và tự nhiên theo cách viết Python.

## Bài tập 1: Vector

Tạo lớp `Vektor` có hai thuộc tính `x` và `y`.

1. Cài đặt `__str__` để vector được hiển thị dưới dạng `(x, y)`.
2. Cài đặt `__add__` để có thể cộng hai vector (`v3 = v1 + v2`).
3. Tạo hai vector, cộng chúng và in kết quả.

### Lời giải

```python
class Vektor:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        return f"({self.x}, {self.y})"

    def __add__(self, other):
        if not isinstance(other, Vektor):
            return NotImplemented
        return Vektor(self.x + other.x, self.y + other.y)


v1 = Vektor(2, 3)
v2 = Vektor(4, 5)

v3 = v1 + v2

print(v1)  # (2, 3)
print(v2)  # (4, 5)
print(v3)  # (6, 8)
```

### Giải thích

- `__init__` lưu tọa độ `x` và `y`.
- `__str__` quyết định nội dung được hiển thị khi dùng `print()`.
- `__add__` được gọi khi sử dụng toán tử `+` và tạo một vector mới có tọa độ bằng tổng các tọa độ tương ứng.

Ví dụ, `v1 + v2` tương đương với `(2 + 4, 3 + 5)`, kết quả là `(6, 8)`.

## Bài tập 2: So sánh (`__eq__`)

Thêm phương thức `__eq__`, trả về `True` nếu hai vector có cùng tọa độ `x` và `y`. Sau đó kiểm tra kết quả so sánh.

### Lời giải

```python
class Vektor:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        return f"({self.x}, {self.y})"

    def __add__(self, other):
        if not isinstance(other, Vektor):
            return NotImplemented
        return Vektor(self.x + other.x, self.y + other.y)

    def __eq__(self, other):
        if not isinstance(other, Vektor):
            return NotImplemented
        return self.x == other.x and self.y == other.y


v1 = Vektor(2, 3)
v2 = Vektor(4, 5)
v3 = Vektor(2, 3)

print(v1 + v2)   # (6, 8)
print(v1 == v2)  # False
print(v1 == v3)  # True
print(v1 == 10)  # False
```

### Vì sao dùng `NotImplemented`?

Khi so sánh vector với một đối tượng thuộc kiểu khác, ví dụ `Vektor(2, 3) == 10`, phương thức trả về `NotImplemented` để báo rằng nó không tự xử lý được trường hợp này. Python có thể thử cách xử lý khác hoặc áp dụng quy tắc so sánh mặc định.

## Bảng tổng hợp phương thức

| Phương thức | Công dụng | Ví dụ |
|---|---|---|
| `__str__` | Hiển thị đối tượng dưới dạng văn bản dễ đọc | `print(v1)` |
| `__repr__` | Biểu diễn đối tượng dành cho lập trình viên | `repr(v1)` |
| `__add__` | Cộng các đối tượng | `v1 + v2` |
| `__eq__` | So sánh hai đối tượng bằng nhau | `v1 == v2` |
| `__len__` | Trả về độ dài đối tượng | `len(obj)` |
| `__getitem__` | Truy cập bằng chỉ số | `obj[0]` |
| `__call__` | Cho phép gọi đối tượng như một hàm | `obj()` |

## Ghi nhớ

Thông thường, bạn không cần gọi trực tiếp các phương thức ma thuật. Chỉ cần viết `v1 + v2`, Python sẽ tự động dùng `__add__`. Nhờ vậy, các lớp tự định nghĩa có thể hoạt động tương tự những kiểu dữ liệu tích hợp sẵn trong Python.
