# 07 – Module và cách tách mã nguồn trong Python

Khi chương trình có nhiều dòng lệnh, chúng ta nên chia mã nguồn thành nhiều tệp. Trong Python, việc này được thực hiện bằng **module** và **package**.

Việc tách mã nguồn có một số lợi ích:

1. **Dễ đọc, dễ quản lý:** `main.py` giữ phần logic chính, còn các hàm và lớp hỗ trợ được đặt trong những tệp riêng.
2. **Tái sử dụng:** Module chứa các hàm toán học có thể được dùng trong nhiều dự án.
3. **Không gian tên (namespace):** Hàm `save()` trong module cơ sở dữ liệu có thể tồn tại riêng với hàm `save()` trong module xử lý tệp.

## 1. Module là gì?

Module là một tệp Python có phần mở rộng `.py`.

Ví dụ, nếu có tệp `matematika.py`, ta có thể nhập tệp đó dưới tên module `matematika`.

## 2. Cách import (nhập module)

Để sử dụng mã từ một tệp khác, chúng ta cần **import** nó.

### A) Import toàn bộ module

```python
import matematika

print(matematika.PI)
```

Cách này dùng cú pháp dấu chấm: tên module, dấu chấm, rồi đến tên biến hoặc hàm.

### B) Import một hàm hoặc biến cụ thể

```python
from matematika import PI, vypocitej

print(PI)
```

Sau khi import, có thể dùng trực tiếp các tên đã nhập mà không cần viết tên module phía trước.

### C) Đổi tên module bằng alias

```python
import matematika as m

print(m.PI)
```

Alias hữu ích khi tên thư viện dài. Ví dụ quen thuộc là `import pandas as pd`.

## 3. Điều kiện `if __name__ == "__main__":`

Mỗi module có một biến đặc biệt tên là `__name__`.

- Khi chạy trực tiếp một tệp, chẳng hạn `python pozdrav.py`, giá trị `__name__` sẽ là `"__main__"`.
- Khi import tệp đó từ một module khác, `__name__` thường là tên module, ví dụ `"pozdrav"`.

Nhờ điều kiện này, ta có thể tách phần định nghĩa hàm và lớp khỏi phần mã dùng để chạy thử. Đoạn mã kiểm tra chỉ chạy khi tệp được chạy trực tiếp.

```python
# Tệp: pozdrav.py

def ahoj():
    print("Xin chào!")

if __name__ == "__main__":
    # Chỉ chạy khi thực thi trực tiếp pozdrav.py
    ahoj()
```

## 4. Package là gì?

Package là cách tổ chức các module liên quan vào cùng một thư mục. Tệp `__init__.py` thường được dùng để đánh dấu package và có thể chứa mã khởi tạo. Trong các phiên bản Python hiện đại, một số package có thể không cần tệp này, nhưng người mới học vẫn nên biết cách sử dụng nó.

### Ví dụ cấu trúc dự án

```text
muj_projekt/  
│  
├── main.py             <-- Vstupní bod aplikace  
└── utils/              <-- Balíček (složka)  
    ├── __init__.py     <-- Inicializační soubor  
    ├── database.py     <-- Modul A  
    └── email.py        <-- Modul Bl
```

### Import tuyệt đối và import tương đối

#### A) Import tuyệt đối

Import tuyệt đối ghi rõ đường dẫn module tính từ package hoặc dự án, tùy cách chương trình được chạy. Với người mới học, cách này thường dễ đọc hơn.

```python
# Tệp: utils/email.py
from utils.database import uloz_log
```

#### B) Import tương đối

Import tương đối sử dụng dấu chấm để chỉ package hiện tại hoặc package cấp trên:

- `.` – package hiện tại.
- `..` – package cấp trên.

```python
# Tệp: utils/email.py
from .database import uloz_log
```

**Lỗi thường gặp:** Import tương đối thường hoạt động khi module được chạy như một phần của package. Nếu chạy trực tiếp tệp `utils/email.py`, Python có thể không biết package cha là gì và báo lỗi `ImportError: attempted relative import with no known parent package`.

## 5. Phụ thuộc vòng tròn (circular imports)

Phụ thuộc vòng tròn xảy ra khi hai module import lẫn nhau.

Ví dụ:

```python
# Tệp: hrac.py
from hra import game_over

def zautoc():
    if zdravi <= 0:
        game_over()
```

```python
# Tệp: hra.py
from hrac import zautoc

def spust_hru():
    zautoc()
```

Khi Python tải `hrac.py`, nó import `hra.py`. Sau đó `hra.py` lại cố import `hrac.py`. Một trong hai module có thể chưa được tải xong, dẫn đến lỗi import.

### Cách tránh phụ thuộc vòng tròn

1. **Chuyển phần mã dùng chung sang module thứ ba.** Ví dụ tạo `spolecne.py` hoặc `config.py`. Hai module còn lại cùng import các hàm hoặc hằng số từ module này.
2. **Import bên trong hàm.** Việc import chỉ diễn ra khi hàm được gọi. Cách này đôi khi phá được vòng lặp, nhưng trước tiên nên cân nhắc tổ chức lại cấu trúc dự án.

Ví dụ import bên trong hàm:

```python
# Tệp: hrac.py

def zautoc():
    from hra import game_over
    game_over()
```

Import bên trong hàm không phải giải pháp cho mọi trường hợp; chỉ nên dùng khi phù hợp với cấu trúc chương trình.

## Bài tập 1: Tạo module riêng

1. Tạo tệp `geometrie.py` và viết hàm `obvod_kruhu(r)` để tính chu vi hình tròn.
2. Thêm khối `if __name__ == "__main__":` để chạy thử hàm và in kết quả.
3. Tạo tệp `hlavni.py`, import module `geometrie` và gọi hàm `obvod_kruhu`.
4. Chạy `hlavni.py` và kiểm tra rằng phần mã chạy thử trong `geometrie.py` không tự chạy khi import.

### Lời giải mẫu

Tệp `geometrie.py`:

```python
import math

def obvod_kruhu(r):
    return 2 * math.pi * r

if __name__ == "__main__":
    print(obvod_kruhu(5))
```

Tệp `hlavni.py`:

```python
import geometrie

print(geometrie.obvod_kruhu(5))
```

Khi chạy `hlavni.py`, chương trình chỉ in kết quả từ lời gọi trong `hlavni.py`. Khối kiểm tra trong `geometrie.py` không chạy khi module được import.

## Bài tập 2: Import một hàm cụ thể

Sửa cách import trong `hlavni.py` để có thể gọi trực tiếp `obvod_kruhu(5)` mà không cần viết `geometrie.` phía trước.

### Lời giải

```python
from geometrie import obvod_kruhu

print(obvod_kruhu(5))
```

## Tóm tắt

- **Module** là một tệp `.py`.
- **`import modul`** cho phép truy cập tên bằng cú pháp `modul.ten`.
- **`from modul import ham`** import một tên cụ thể.
- **`if __name__ == "__main__":`** phân biệt việc chạy trực tiếp với việc import module.
- **Package** giúp sắp xếp các module trong thư mục.
- **Import vòng tròn** xảy ra khi các module import lẫn nhau; thường có thể xử lý bằng cách tổ chức lại mã nguồn và trách nhiệm của từng module.
