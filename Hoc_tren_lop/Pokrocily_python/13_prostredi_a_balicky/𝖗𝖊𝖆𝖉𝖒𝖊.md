# **13 - Môi trường ảo và quản lý gói**

Khi làm việc trên nhiều dự án, bạn sẽ gặp một vấn đề được gọi là
**"Dependency Hell"** (xung đột phụ thuộc).

-   Dự án A cần thư viện `requests` phiên bản 1.0.
-   Dự án B cần thư viện `requests` phiên bản 2.0.

Nếu cài đặt thư viện trên toàn hệ thống, bạn không thể sử dụng đồng thời
cả hai phiên bản. Giải pháp là **môi trường ảo**.

## **1. Môi trường ảo (`venv`)**

Môi trường ảo là một thư mục được cô lập, chứa bản sao riêng của trình
thông dịch Python và thư mục riêng dành cho các thư viện
(`site-packages`).

### **Cách tạo venv (Terminal)**

``` python
# Windows  
python -m venv .venv

# Linux / Mac  
python3 -m venv .venv
```

Lệnh này tạo thư mục `.venv` (bạn có thể tùy chọn tên khác, nhưng
`.venv` là tên tiêu chuẩn).

### **Cách kích hoạt venv**

Sau khi tạo, chúng ta cần cho terminal biết rằng hãy sử dụng Python
trong môi trường này thay vì Python của hệ thống.

-   **Windows (PowerShell):** `.venv\Scripts\Activate.ps1`
-   **Windows (CMD):** `.venv\Scripts\activate.bat`
-   **Linux / Mac:** `source .venv/bin/activate`

Sau khi kích hoạt, bạn sẽ thấy `(.venv)` xuất hiện trong dòng lệnh.

## **2. Trình quản lý gói (`pip`)**

`pip` (Pip Installs Packages) là công cụ dùng để tải thư viện từ [PyPI
(Python Package Index)](https://pypi.org).

**Lưu ý quan trọng:** Trong các phiên bản Python gần đây (và nhiều bản
phân phối Linux), việc **cài đặt gói trên toàn hệ thống thường bị cấm**
vì lý do bảo mật (lỗi `error: externally-managed-environment`). Bằng
cách này, hệ thống buộc bạn sử dụng môi trường ảo để tránh làm hỏng các
công cụ hệ thống phụ thuộc vào Python.

### **Các lệnh cơ bản**

-   `pip install ten_goi` - Cài đặt phiên bản mới nhất.
-   `pip list` - Hiển thị các gói đã cài đặt.
-   `pip uninstall ten_goi` - Gỡ cài đặt một gói.

## **3. Tệp `requirements.txt`**

Để có thể chia sẻ dự án với người khác (những người không có thư mục
`.venv` của chúng ta), cần tạo một danh sách các thư viện phụ thuộc.

### **Tạo danh sách (Freeze)**

Lưu trạng thái hiện tại của môi trường vào một tệp:

``` shell
pip freeze > requirements.txt
```

### **Cài đặt từ danh sách**

Khi ai đó tải dự án của bạn về, họ tạo một môi trường venv trống rồi
chạy:

``` shell
pip install -r requirements.txt
```

Nhờ đó, chính xác những phiên bản thư viện mà dự án yêu cầu sẽ được cài
đặt.

## **Bài tập**

### **1. Tệp kê khai (Lý thuyết)**

Tạo một tệp văn bản `requirements.txt` để sử dụng cho dự án có các yêu
cầu sau:

-   Thư viện `requests` phải ở chính xác phiên bản `2.28.1`.
-   Thư viện `flask` có thể ở bất kỳ phiên bản nào.

### **2. Các lệnh (Lý thuyết)**

Viết một chuỗi lệnh dành cho Linux để:

1.  Tạo môi trường ảo.
2.  Kích hoạt môi trường đó.
3.  Cài đặt gói `numpy`.
