# **13 - Môi trường ảo và quản lý gói**

Máy tính của bạn có một Python chính. Bên trong đó có nhiều thư viện.

Nếu tất cả dự án đều dùng chung Python này, chúng có thể xung đột phiên bản được gọi là
**"Dependency Hell"** (xung đột phụ thuộc).

Vì vậy, chúng ta tạo môi trường riêng cho từng dự án 

-   Dự án A cần thư viện `requests` phiên bản 1.0.
-   Dự án B cần thư viện `requests` phiên bản 2.0.

Nếu cài đặt thư viện trên toàn hệ thống, bạn không thể sử dụng đồng thời
cả hai phiên bản. Giải pháp là **môi trường ảo**.

## **1. Môi trường ảo (`venv`)**

Môi trường ảo là một thư mục được cô lập, chứa bản sao riêng của trình
thông dịch Python và thư mục riêng dành cho các thư viện
(`site-packages`).

### **Cách tạo venv (Terminal)**

``` python
# Windows  
python -m venv .venv

# Linux / Mac  
python3 -m venv .venv
```

Lệnh này tạo thư mục `.venv` (bạn có thể tùy chọn tên khác, nhưng
`.venv` là tên tiêu chuẩn).

### **Cách kích hoạt venv**

Sau khi tạo, chúng ta cần cho terminal biết rằng hãy sử dụng Python
trong môi trường này thay vì Python của hệ thống.

-   **Windows (PowerShell):** `.venv\Scripts\Activate.ps1`
-   **Windows (CMD):** `.venv\Scripts\activate.bat`
-   **Linux / Mac:** `source .venv/bin/activate`

Sau khi kích hoạt, bạn sẽ thấy `(.venv)` xuất hiện trong dòng lệnh.

### **Cách Tắt môi trường ảo (Deactivate)**

Khi không muốn sử dụng môi trường ảo nữa, bạn nhập:

`deavtivate`

## **2. Trình quản lý gói (`pip`)**

Bạn đã biết `import requests` có nghĩa là sử dụng thư viện requests.

Nhưng nếu máy tính chưa cài thư viện này thì sao?

Bạn cần cài đặt nó.

Đó chính là nhiệm vụ của `pip`.

### **Các lệnh cơ bản**

-   `pip install ten_goi` - Cài đặt phiên bản mới nhất.
-   `pip list` - Hiển thị các gói đã cài đặt.
-   `pip uninstall ten_goi` - Gỡ cài đặt một gói.
-   `pip install ten_goi==phien_ban` - Cài phiên bản cụ thể

## **3. Tệp `requirements.txt`**

Giả sử bạn làm một dự án Python và đã cài 5 thư viện:
```python
requests
numpy
flask
pandas
beautifulsoup4
```
Sau đó bạn muốn gửi dự án cho một người bạn.
Bạn gửi code cho họ nhưng họ không có các thư viện này.
Họ chạy chương trình sẽ gặp lỗi

Vậy làm sao để họ biết cần cài những thư viện nào?
Chúng ta sử dụng `requirements.txt.`
Đây là file chứa danh sách các thư viện mà dự án cần.

### **Tạo danh sách (Freeze)**

Lưu trạng thái hiện tại của môi trường vào một tệp:

``` shell
pip freeze > requirements.txt
```

### **Cài đặt từ danh sách**

Khi ai đó tải dự án của bạn về, họ tạo một môi trường venv trống rồi chạy:

``` shell
pip install -r requirements.txt
```

Pip sẽ đọc file và tự động cài các thư viện với phiên bản được khai báo.
